# Final Project — Data Wrangling | ITS

Official dataset and project instruction repository for the Data Wrangling course, Bachelor of Data Science, Institut Teknologi Sepuluh Nopember (ITS).

## Current Final Project

**Advanced Data Wrangling: From Raw Data to Reproducible Data Products**

| Item | Requirement |
|---|---|
| Group size | 2 students |
| Duration | 4 weeks |
| Programming language | Python |
| Dataset | Select one dataset from the `Dataset/` folder |
| Progress checkpoint | End of Week 2 |
| Final deliverables | Public GitHub repository, published Kaggle Notebook, and presentation |

### Project Instructions

**[Read the Complete Final Project Instructions](Instructions/Final_Project_Instructions.md)**

Students must complete six major tasks:

1. **Data Gathering and Understanding (10%)**
2. **Data Quality Assessment (20%)**
3. **Data Cleaning and Transformation (25%)**
4. **Data Validation and Reproducibility (15%)**
5. **Exploratory Data Analysis and Interpretation (15%)**
6. **Documentation and Public Publication (15%)**

### Available Datasets

Select one dataset from the [Dataset folder](Dataset/):

- Hotel Bookings Data
- NFL Attendance Data
- Spotify Genre Data

### Important Requirements

- Both GitHub and Kaggle publication are mandatory.
- Students must compare alternative preprocessing strategies.
- Automated data validation and reproducibility are required.
- A progress checkpoint will take place at the end of Week 2.
- Final grades consist of 85% group project performance and 15% individual contribution and understanding.
- Kaggle views, upvotes, and medals are not grading criteria.

### Submission

Submit the GitHub repository URL, published Kaggle Notebook URL, final report, and presentation slides through MyClassroom.

The official deadline will be announced through MyClassroom.
